应用简介

氢计划是一个纯本地的日程与行程工具：日历、条目、计划、行程表和天气。没有账号，也没有服务端。

提醒由系统本地通知调度，应用关闭或锁屏后仍会触发。

数据存放

条目、计划、分类、设置和同意记录保存在本机：优先 IndexedDB（light-schedule-db），不可用时退回 localStorage。

没有服务器，我们不会持有你的数据副本。

卸载应用或清除应用数据会删除全部本地内容。换机或清理前请先导出备份。

网络请求与数据去向

只有天气与地址搜索会联网。它们发出的是搜索关键词和所选地点的坐标，收件方只有下列服务。

天气：只发送所选地点的经纬度（保留 3 位小数，约 100 米精度），发给 Open-Meteo。

城市与地点搜索：只发送你输入的搜索关键词，发给 Photon（基于 OpenStreetMap 数据）。

地址搜索：只发送你输入的搜索关键词，发给 Photon。

不会发送日程正文、备注、分类、计划、备份文件内容、账号信息、通讯录、相片，也不会发送设备型号。

所有请求都由设备用 HTTPS 直连上述服务，不经过本项目中转；应用没有统计、广告或崩溃上报 SDK。

权限清单

通知：用于到点提醒。拒绝后应用仍可使用，但收不到提醒。

闹钟与提醒（Android 12 及以上）：用于准时触发提醒。拒绝后提醒可能延后或漏掉。

存储（旧版 Android）：只用于导出备份和读取你选择的备份文件。拒绝后无法导出或恢复。

振动：用于选择日期、时间时的轻触反馈。关闭后只是没有触感，不影响功能。

本应用不申请定位权限，也不读取设备位置。

备份文件

备份是 JSON 文件，当前未加密，含条目、计划、分类、设置和同意记录。

备份生成后交给系统的保存或分享面板，应用内不留副本，临时文件用完即删。

文件可能被网盘、聊天工具或他人看到，请存放到你可信的位置。

提醒的局限

系统清理后台、省电模式或权限关闭时，提醒可能延迟，甚至不触发。

重要事项请同时在系统闹钟里设一次提醒。这是本应用的真实边界。

同意记录

本机尚未记录同意。

这条记录只存在本机，清除应用数据或卸载会一并删除。

数据来源

天气与预报：Open-Meteo。请求只包含所选地点的经纬度。

城市与地点搜索：Photon，基于 OpenStreetMap 数据。

OpenStreetMap 数据版权归 OpenStreetMap 贡献者，许可 ODbL。

以上请求都由设备直接发起，不经过本项目中转。

字体与图标许可

站酷小薇 ZCOOL XiaoWei（中文）与 Cormorant Garamond（英文）：SIL Open Font License 1.1，随应用本地打包。

Lucide 图标集：ISC License，SVG 内联，随应用本地打包。

应用图标与启动图随应用本地打包。字体和图标都不从网络加载。

签名与安装包

官方签名指纹：生成新密钥后填入（见 README）

从非官方渠道获得、或签名指纹不一致的安装包，可能已被修改，请勿使用。

客户端没有「不可破解的加密」：混淆只提高改动成本，真正阻止第三方改包的是系统的签名校验。

开始使用前

氢计划用手机的系统通知提醒你安排的事。通知只在你自己的手机上生成，不会上传到任何地方。

通知与提醒 检测中…

提醒由系统排程，关掉应用或锁屏后也会按时通知；系统限制后台运行时可能略有延迟。

系统拒绝了通知权限。可以打开手机「设置 → 应用 → 氢计划 → 通知」把通知打开，再回到这里点下面的按钮重新检查。

存储与备份 检测中…

备份不会写进应用私有目录：生成后交给系统的保存 / 分享面板，由你决定存到哪里；临时文件用完即删。

提醒可能因系统限制后台运行而略有延迟；重要事项请同时在系统闹钟里设一次。
